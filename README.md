# A2Helper

Companion app e medidor de combate para **Aion 2**.

## Download

Baixe o instalador mais recente em **[Releases](../../releases/latest)** (`A2Helper-Setup-x.y.z.exe`).

Depois de instalado, o A2Helper se atualiza sozinho.

> Este repositório guarda só os instaladores e as atualizações.
